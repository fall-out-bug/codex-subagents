# Roadmap

## v0.1

- Synchronous `run/status/result/list`
- Runtime adapters for `pi`, OpenCode, and GSD2
- Durable local run directory

## v0.2

- Background execution with PID tracking
- `cancel` command
- Structured result parser with `pass`, `fail`, `partial`, and `not_assessed`
- Safer timeout and signal handling

## v0.3

- Worktree isolation for write-capable agents
- Built-in profiles: `explore`, `review`, `implement`, `evidence`, `gsd2-plan`
- JSON event streaming for OpenCode

## v0.4

- Codex skill wrapper
- Parallel fan-out helpers
- Merge/adjudication helpers for reviewer panels
